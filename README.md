# ONG Esperança e Ação — Experiência Prática III

Projeto reorganizado para a etapa de **Fundamentos e organização inicial**, seguindo a separação de responsabilidades.

## Estrutura

- `html/` — páginas HTML da aplicação.
- `css/` — arquivos de estilização.
- `imagens/` — recursos gráficos.
- `js/` — lógica JavaScript e futuros módulos.

O arquivo `js/main.js` foi criado como ponto de entrada para as funcionalidades JavaScript que serão desenvolvidas nas próximas etapas.
